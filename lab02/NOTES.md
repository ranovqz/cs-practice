Git — это система контроля версий (Version Control System, VCS), а GitHub — облачная платформа для хостинга Git-репозиториев и совместной работы над проектами.



Использованные команды:

git status - чтобы понять, что именно нужно зафиксировать.

git diff - команда показывает различия между рабочим каталогом и индексом.

git diff --staged - эта команда показывает различия между индексом и последним коммитом



Ветки:

* Ветки позволяют работать над разными задачами параллельно, не затрагивая основную версию проекта. 
* При новом коммите в ветке указатель ветки просто сдвигается на новый коммит. 
* Слияние объединяет изменения из одной ветки в другую, сохраняя историю обеих веток. 
* При возникновении конфликтов слияния их нужно разрешать вручную перед завершением процесса
