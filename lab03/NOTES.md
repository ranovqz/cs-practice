git diff — сравнение состояний (что изменилось).

git show — детали коммита (метаданные + патч от предыдущего).

git log — обзор истории коммитов (можно с фильтрами).

git log -S — поиск добавлений/удалений строки в diff коммита.

git blame — история конкретного места в файле (кто и когда менял строку).



Используйте git restore <file>, если хотите просто отменить локальные правки в файле, не трогая историю коммитов.

Используйте git restore --source=..., если вам нужна конкретная, более ранняя версия файла из истории репозитория. Это удобно, когда файл менялся в нескольких коммитах, и вам нужна определённая правка.
